# 실제 성공한 멀티턴 시연 후보

**후속 적용 완료:** 사용자 승인 뒤 D6 + 전체 보강 +16K를 운영 기본값으로 반영했다. [최신 적용 검증](2026-11-05_d6_prompt_adoption.md): 필수17/17, 상태·계획80/82, 전체 계약77/82. 아래 대화/점수·미교체 표시는 이전 비교 평가 당시 기록이다. 검증 서버는 종료했다.

**평가상 D6/Q6/Pbest150, 16K, 고정 실행 안내 조건의 실제 출력이다. 운영 어댑터 교체는 아직 없다.**

서로 독립된 시작 상태를 쓰는5개 시나리오이다. 이 목록을 이어 붙인 긴 대화를 검증한 것은 아니다. 1~4는 기존 Decision prompt, 5는 보강 prompt 시험 결과이다. 모든 답변을 모델로 생성한 것이 아니며 출처를 구분한다. 실제 로봇 없이 완료 fixture로 단계 전환했다. 계획의 ×숫자는 repeat_count이며 무게나 재료 개수가 아니다. 한 번의 성공으로 모든 캐시/다른 표현에서 성공을 보장하지 않는다.

## 모델 실행 안내와 차이

같은 명시적 실행 문장에는 모델도 “크림 소스를 선택했고 얇은면은 보통 양으로 담을게요.”라고 정상 응답했다. 수량 수정 후 모델 출력도 이번에는 양파/버섯 적게로 맞았다. 하지만 별도 모호성 대화에서 버섯 제거와 양파 실행을 함께 요청했을 때 실행 누락이 남았고, 동일 입력의 캐시 조건별 변동도 별도 조사했다. 따라서 이 목록은 고정 실행 안내를 시연 기준으로 삼는다.

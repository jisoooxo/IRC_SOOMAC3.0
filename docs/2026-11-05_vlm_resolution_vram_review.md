# VLM7장 입력 해상도별 VRAM 추가 확인

**해상도별 실제 추론·동시 부하·정리 완료. 다만 실제 운영 이미지 토픽의 해상도는 UNKNOWN이다.** ROS 도메인17에서45초 구독했으나 `/vision/overlay_image` 발행자0·수신0이었다. 로컬비전 코드의 색상 스트림640×480 설정을 근거로 시험했으며, 이를 실제 외부 overlay 토픽의 해상도로 확정하지 않는다.

## 입력과 실행 조건

LLM은 `/vision/overlay_image`의 `CompressedImage`를 받으며 최근5프레임을 보관한다. 압축 해제 뒤RGB로 바꿀 뿐 이 단계에서 크기를 줄이지 않는다. 이미지 요청은 **RAG참고1 + 이전비교1 + 현재관측5 =7장**이다. 근거: `llm_langgraph_node.py:74`, `:255`, `:267`, `:321`, `vlm.py:72`. 로컬카메라 설정은 `detect_yolo_sam_obb_pub.py:71`이며 해당 소스의 camera설정과 외부 overlay발행 크기의 동일성은 미확인이다.

저장된512×512이미지6장을 시험 크기로 리사이즈했다. 현재5장은JPEG quality95로 인코딩하고 실제 노드의 camera_callback → 압축해제 → snapshot 경로를 통과시켰다. 이전1장은같은크기의PIL이미지, RAG참고1장은202×415원본이다. 실제 DDS전송을 받은 입력이나 시간적으로 이어진 현장영상은 아니므로 판정 정확도 검증이 아니다. 원래VLM프롬프트/이미지처리코드는변경하지않았다.

임시12,288토큰/예약.50, NF4/BF16, D6/Q6/Pbest150·전체보강을유지했다. Qwen3-ASR1.7B BF16·CosyVoice3·실제LLM/UI/MAIN을ROS217localhost에서동시상주했다. STT10초·일반TTS·기존9,067토큰Decision입력으로워밍업한뒤VLM을실행했다. 이번에는필수17턴전체를다시돌리지않았으므로직전시험과allocator/LoRA사용이력이같다고주장하지않는다.

## 실측

| 입력/부하 | GPU전체 관측peak | 최소여유 | VLM 입력토큰 | VLM명령 소요 |
|---|---:|---:|---:|---:|
| 현재5+이전1을640×480,참고1원본 |26.54GiB|5.32GiB|2,408|2.17초|
| 현재5+이전1을1920×1080,참고1원본 |26.54GiB|5.32GiB|2,396|3.25초|
| Full HD7장 + Qwen30초음성 + 긴TTS 동시부하 |27.83GiB|4.03GiB|2,396|3.16초|

명령소요에는 파일읽기/변환/요청이포함된다. 동시부하표의peak는시작을맞춘작업묶음전체의최고값이며세모델이동일순간모두kernel을실행했다는증거는아니다.7장VLM의응답은모두정상종료했다. raw의PASS문구는저장이미지부하시험출력일뿐실제작업성공을뜻하지않는다.

NVML50ms표본이며드라이버예약약0.49GiB와데스크톱을포함한다. 순간최고를모두포착한상한보장은아니다. 이번run최고27.83GiB가이전동시부하28.97GiB기록을대체하지않는다. 전체관측중보수적으로사용할기록은12K/.50의**28.97GiB/최소여유2.89GiB**이다.

`processor_config.json`의image_processor.max_soft_tokens=280,image_seq_length=280,do_resize=true를읽었다. 원본해상도가커져도모델전처리뒤토큰수가비례증가하지않는설정이며실제요청에서도640입력2,408/FHD2,396토큰이었다. 비율별처리차이의세부원인이나해상도별판정품질은이번에검증하지않았다.

## 판정과 현재 상태

12K/.50이이번640×480/FHD7장및음성동시부하를완주한운영후보라는판정이다. 실시간토픽해상도확인/실물판정정확도/장시간안정성완료로확대하지않는다. 운영기본값은아직16K/.58이며이번변경은시험프로세스한정이다.

소유scope6개inactive,GPUcompute빈목록,5000/8000포트반환. runtime/source41개해시불변. 원본어댑터·VLM파일·정책·원격/로봇제어변경없음.

Cause:실제이미지발행자가없어서수신프레임에서해상도를읽을수없었다.
Effect:코드설정크기와FHD로7장이미지부하를추가확인했고,실제토픽해상도는미확인으로남겼다.

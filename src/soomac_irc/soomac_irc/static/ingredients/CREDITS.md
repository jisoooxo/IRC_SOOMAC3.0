# 재료 사진 출처

UI 표시 전용 사진이다. VLM 기준 이미지(ChromaDB)와는 무관하다.
누끼(배경 제거)는 pngimg 원본이거나 BiRefNet(ZhengPeng7/BiRefNet, MIT)으로 땄고, 웜톤으로 통일 보정했다(R×1.04, B×0.92, 채도 -10%).

| 파일 | 출처 | 라이선스 |
| --- | --- | --- |
| noodle.webp | https://pngimg.com/uploads/pasta/pasta_PNG98596.png (가닥 방향으로 늘림) | CC BY-NC 4.0 (pngimg.com) |
| sausage.webp | 사용자 제공 레퍼런스 (프랑크 소시지) | 학생 대회 내부 사용 |
| mushroom.webp | 사용자 제공 레퍼런스 (느타리버섯) | 학생 대회 내부 사용 |
| cheese.webp | Pinterest 검색 이미지 (채 썬 모짜렐라) | 학생 대회 내부 사용 |
| onion.webp | Pinterest 검색 이미지 (채 썬 흰 양파) | 학생 대회 내부 사용 |
| pepperoncino.webp | 저장소 원본 pepperoncino.webp (웜톤 보정만) | 학생 대회 내부 사용 |
| crab.webp | Pinterest 검색 이미지 (맛살 더미) | 학생 대회 내부 사용 |
| vegetable_combo.webp | mushroom.webp + onion.webp 합성 | 위 두 출처를 따름 |

cover, cream, oil, tomato 는 기존 파일을 그대로 쓴다.
